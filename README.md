## 🚀 How to Run the Website Locally

You can run the website in any of the following ways:

### Method 1: Using the Built-In Local Server (Recommended)
Open your terminal in this directory and run:
```bash
npm start
```
or
```bash
node server.js
```
Then visit **`http://localhost:3000`** in your browser.

### Method 2: Open Directly in Your Browser
Simply double-click **`index.html`** in this folder to open the site directly in Chrome, Edge, Safari, or Firefox.
